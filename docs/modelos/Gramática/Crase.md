# Crase

## Regra

Crase é a fusão da preposição **a** com o artigo **a(s)** (ou com o **a** inicial de *aquele*, *aquela*, *aquilo*). Só há crase se o verbo ou nome pede a preposição **e** a palavra seguinte aceita o artigo feminino.

## Exemplos

```exemplo
errado: Fui [a]{erro} feira ontem.
certo: Fui [à]{ok} feira ontem.
porquê: Quem vai, vai **a** algum lugar (preposição) e "feira" aceita "a" (artigo).

errado: Voltei [à]{erro} pé para casa.
certo: Voltei [a]{ok} pé para casa.
porquê: "Pé" é masculino: não há artigo, então não há crase.
```

## Exceções e dúvidas

- Antes de palavra masculina não há crase, salvo a expressão *à moda de* (*à Luís XV*) subentendida.
- Antes de verbo não há crase: *começou a chover*.
- Antes de pronome de tratamento (*senhora*, *Vossa Excelência*) em geral não há crase; com *senhora* e *dona* ela é facultativa.
- Horas: **à** uma hora, **às** duas horas; hora exata e determinada leva crase.

## Como testar

Troque a palavra feminina por uma masculina: se aparecer **ao**, há crase. *Fui à feira* → *Fui ao mercado*.
