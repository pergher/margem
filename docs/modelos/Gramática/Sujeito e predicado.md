# Sujeito e predicado

## Regra

**Sujeito** é o termo de quem se declara algo; **predicado** é o que se declara. O verbo é o núcleo do predicado.

## Exemplos

```sintaxe
[Os alunos]{sujeito} [[leram]{verbo} [o livro]{objeto direto} [na biblioteca]{adjunto adverbial}]{predicado}.
```

```exemplo
errado: [Choveu]{erro} chuva ontem.
certo: Choveu ontem.
porquê: Verbos de fenômeno da natureza não têm sujeito; "chuva" seria redundante.
```

## Exceções e dúvidas

- Oração sem sujeito: *Choveu*, *Há flores*, *Faz frio*.
- Sujeito oculto (elíptico): *Cheguei cedo* (eu).

## Como testar

Pergunte "quem?" ao verbo; a resposta é o sujeito.
